# 졸업앨범 단체사진 셀렉

학생 모둠은 반별 사진 중 **모둠 사진 1장**을 고르고, 교사는 **반 단체사진 1장**을 고릅니다.
최종관리자는 전체 현황을 보고, 업체에 넘길 파일을 이름을 바꾼 상태로 내려받습니다.

| 누가 | 주소 | 할 수 있는 일 |
| --- | --- | --- |
| 학생(모둠) | `/` | 반·조를 고르고 비밀번호로 로그인 → **자기 반 사진만** 보고 1장 셀렉 (`O반_O조.jpg`) |
| 교사 | `/admin` → 교사 로그인 / 교사 등록 | 드라이브 전체 사진에서 단체사진을 골라 몇 반인지 입력 (`O반_단체.jpg`). 담당 반 모둠 셀렉 확인, 원본 저장·ZIP·CSV, 모둠 비밀번호 초기화 |
| 최종관리자 | `/admin` → 최종관리자 | 모든 반 현황, **어떤 교사가 어떤 단체사진을 골랐는지**, 등록 교사 목록, 전체 기록(누가 언제 무엇을 했는지), 셀렉 마감, 전체 ZIP·CSV |

- 모둠·반마다 한 장만 저장됩니다(DB 기본키로 막음). 다시 고르면 새 사진으로 바뀌고, 바뀐 내용은 모두 기록에 남습니다.
- 모둠이 처음 로그인할 때 입력한 비밀번호가 그 모둠 비밀번호가 됩니다. 잊어버리면 교사가 초기화합니다.
- 최종관리자가 **마감**하면 학생과 교사는 더 이상 바꿀 수 없습니다.

## 구글 드라이브 준비

1. 사진 폴더(기본값 `1QobfIH_5WpmLVjGUve5CxEeS2p-DtFk2`)를 **링크가 있는 모든 사용자 – 뷰어**로 공유합니다.
2. 폴더 안에 `1반`, `2반` … `5반` 하위 폴더를 만들고 사진을 넣습니다. 하위 폴더는 2단계까지 읽습니다.
   반 번호가 없는 폴더의 사진과 최상위 폴더에 바로 있는 사진은 ‘기타 폴더’로 묶여 교사에게만 보입니다.
3. Google Cloud Console에서 프로젝트를 만들고 **Google Drive API**를 사용 설정한 뒤 `사용자 인증 정보 → API 키`를 만듭니다.
   키 제한에서 API를 *Google Drive API*로만 제한하세요.

원본 사진은 드라이브에 그대로 남고, 앱은 읽기만 합니다.

## Vercel 배포

1. 이 저장소로 Vercel 프로젝트를 만듭니다 (프레임워크: Other, 루트: 저장소 루트).
2. Storage에서 **Neon Postgres**를 연결합니다. `DATABASE_URL`이 자동으로 등록되고, 테이블은 첫 요청 때 자동으로 만들어집니다.
3. 환경 변수:

| 이름 | 설명 |
| --- | --- |
| `GOOGLE_API_KEY` | 위에서 만든 Drive API 키 |
| `DRIVE_FOLDER_ID` | (선택) 사진 폴더 ID. 없으면 기본 폴더 |
| `ADMIN_PASSWORD` | 최종관리자 비밀번호 |
| `TEACHER_SIGNUP_CODE` | 교사 등록 코드 (교사들에게만 알려 주세요) |
| `SESSION_SECRET` | 16자 이상 임의 문자열 (예: `openssl rand -hex 32`) |
| `CLASS_COUNT` / `GROUP_COUNT` | (선택) 반 수(기본 5) / 반당 조 수(기본 8) |

4. 배포한 뒤 `/api/health`를 열어 봅니다. 각 항목이 `ok` 또는 `configured`이고 반별 사진 수가 보이면 준비가 끝난 것입니다.

## 참고

- 원본 저장은 서버가 드라이브 원본을 그대로 전달하면서 파일명만 바꿉니다. 아주 큰 파일이 실패하면
  카드의 **드라이브** 버튼으로 받은 뒤 화면에 표시된 저장 파일명으로 바꿔 주세요. **목록 CSV**에 반·조·저장 파일명·원본 파일명·선택한 사람이 모두 들어 있습니다.
- 드라이브 목록은 5분 동안 캐시됩니다. 사진을 새로 올렸다면 ‘드라이브 새로고침’을 누르세요.
- 학생 화면에는 서버가 자기 반 사진만 내려줍니다. 하지만 드라이브 폴더 자체는 링크 공유이므로, 폴더 링크는 학생에게 알리지 마세요.
